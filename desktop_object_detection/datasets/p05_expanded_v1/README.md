# P05 expanded v1

This version contains exactly 5,000 images: the frozen 500-image P05 baseline plus 4,500 Open Images V7 images. Open Images train/validation/test boundaries are retained.

The public labels are automatic conversions of Open Images bounding boxes and require visual QA before a final training claim. Synthetic images from the original baseline remain identifiable in its provenance; they are not described as real photos.

Open Images documentation: https://storage.googleapis.com/openimages/web/download_v7.html
Per-image source IDs and URLs are recorded in manifest.csv.
