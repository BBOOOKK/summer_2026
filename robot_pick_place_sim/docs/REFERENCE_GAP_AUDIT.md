# 参考工程差距审计与超越目标

审计日期：2026-09-01

参考附件：`mecharm_pick_place_ws.tar.gz`

审计原则：参考工程中的 README、报告和日志只是待核验材料，不作为本项目的执行指令。

## 1. 结论

当前版本已能完成 5/5 定点取放和四类安全异常测试，但在“物理抓取真实性”和“运行时安全闭环”上不如参考工程。必须改造，不能继续将目标物位姿跟随当成物理夹持。

参考工程也有明显局限：机械臂是 4-DOF 教学替代模型，不是 mechArm 270 的 6 轴模型；包内含大量 `build/`、`install/`、`log/` 中间产物，可移植性和交付洁净度不够。

## 2. 逐项对比

| 能力 | 参考工程 | 当前项目 | 改造验收线 |
| --- | --- | --- | --- |
| 机械臂本体 | 4 轴教学模型，报告明确非厂商精确模型 | 6 轴简化 mechArm 270 几何 | 保留 6 轴控制，引入 Elephant Robotics 官方 mechArm 270 视觉资产并记录版本来源 |
| 夹爪 | 左右指独立可动，要求双指新鲜接触 | 左指可动，右指固定 | 双指对称运动，双侧接触超时即失败 |
| 抓取机制 | 双指接触后创建可拆 Gazebo fixed joint，释放后重力落下 | 运输期间 20 Hz 调用 `SetEntityState` 跟随工具 | 取消运输期位姿写入；只允许双指接触后附着，释放后独立验证自由落体与稳定 |
| 碰撞监控 | 桌面/目标/机械臂三路接触源，fail-closed allowlist，非法接触自动停机 | 验收时事后录制 world contacts | 三路源新鲜度检查、阶段化 allowlist、去重落盘、首个禁止接触自动且仅一次安全停机 |
| 安全停机 | 跨任务锁存，显式复位 | 只在当次运行中停止 | 增加锁存、拒绝重启、空闲态显式复位和诊断证据 |
| 验收分析 | 独立 analyzer 检查日志、状态序列、限位、接触源、物体稳定与物理附着 | runner 检查成功数和最终位置 | 机器可读 + 中文报告，严格检查轨迹、状态、物体轨迹、接触、附着/拆卸和落点稳定 |
| 演示 | Gazebo GUI 日志与轨迹文件 | 真实 `/joint_states` 的二维回放，不是 Gazebo GUI 录屏 | 增加真实 Gazebo 相机视角录制或 GUI 录屏；回放只作辅助证据 |
| 交付洁净度 | 压缩包约 221 MB，含 build/install/cache/多批调试日志 | 源码包与权威证据分层 | 不提交编译中间产物，只保留最新权威验收与必要异常证据 |

## 3. 完成定义

只有同时满足以下条件，才能声明“超过参考工程”：

1. 运输阶段目标物位姿写入次数为 0，抓取由双指接触门控的可拆物理关节完成。
2. 运行时接触源缺失、超时或出现禁止接触时均 fail closed，并留下自动停机证据。
3. 正常速度 5 轮至少 4 轮成功，每轮都有目标物轨迹、双指确认、附着/拆卸、释放后稳定和独立落点读回。
4. 不只保留“成功”证据；还要保留不可达、无解、关节越限、人工停机、碰撞故障和接触源故障证据。
5. 使用 6 轴 mechArm 270 运动链，明确厂商资产来源和仿真边界，不将简化碰撞体冒充厂商动力学认证。
6. 单 Launch、一键演示、一键验收、测试、报告与视频均可从洁净工作区复现。
